# Usability Testing & Analysis — CampusMate

## Overview
A browser-based usability research workspace for planning and documenting a usability study of the CampusMate student app.

## Deliverables
- Research objectives, participant profile, method, and ethics notes
- Four usability task scenarios with success criteria
- Example participant session log
- Interactive observation capture form
- Post-test participant feedback form
- Usability metrics, findings, recommendations, and iteration plan
- Print-friendly report (use Print → Save as PDF)

## Run
Open `index.html` in a browser. No installation is required.

## Data note
Participant results and metrics are illustrative sample data for demonstrating the report workflow. Replace them with real observations before presenting them as actual user research.
